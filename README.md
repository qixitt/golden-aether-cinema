# 金色天光 · 幻想电影

**Golden Aether Cinema — 用一句话，生成金色天光下的写实幻想画面。**

这是一个可复用的 Codex 图像风格 Skill。它把参考图中的光色、材质、镜头和空间规律整理成生成规则，让你只描述想画什么，就能调用同一套视觉风格。

> 香槟金逆光 · 蓝灰环境 · 通透肤质 · 精细材质 · 幻想电影感

## 它能做什么

- 将一句话扩写为完整图像指令，并在宿主支持时直接生成图片。
- 在不同人物、动物、建筑、器物和场景之间延续统一的视觉气质。
- 根据题材选择近景肖像或有空间层次的环境构图。
- 对用户提供的照片进行风格化，同时保留指定的身份、构图和内容。
- 默认输出一张约 16:9、无文字、无水印的图片；可用自然语言覆盖这些默认值。

它固定的是视觉语言。金发、天使、王冠、云海和翅膀都是可选题材，不会被强行加入每张图片。

## 视觉语言

| 维度 | 风格规则 |
| --- | --- |
| 光线 | 低角度侧逆光，香槟金与奶油白轮廓光，柔和空气散射 |
| 色彩 | 暖金亮部、低饱和蓝灰环境、桃粉肤色，保留冷暖关系 |
| 人物 | 写实基础上的精致感，自然表情、皮肤纹理和细微眼部反光 |
| 材质 | 薄金属、透明晶体、轻纱、蕾丝、珍珠母及层叠羽毛 |
| 镜头 | 主体焦点明确，前景散景、中景层次与远景空气透视 |
| 动势 | 发丝、衣摆与云层沿统一风向形成连续曲线 |
| 情绪 | 宁静、神圣、轻盈，兼具亲近感与宏阔空间 |

## 安装

1. 下载仓库 ZIP 并解压，或克隆仓库。
2. 将包含 `SKILL.md` 的整个文件夹复制到 `~/.codex/skills/golden-aether-cinema/`。
3. 保留 `agents/` 与 `references/`，不要只复制 `SKILL.md`。
4. 在支持本地 Skills 的 Codex 环境中使用；如未被识别，可重启应用后再试。

安装后的目录应为：

```text
~/.codex/skills/golden-aether-cinema/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    ├── portrait.png
    └── cloudscape.png
```

## 一句话使用

```text
$golden-aether-cinema 一位银发女骑士骑着白鹿穿过清晨的悬空花园。
```

```text
$golden-aether-cinema 海边灯塔上的成年女巫近景，黑发被风吹起。
```

```text
$golden-aether-cinema 云层中的古老观星台，没有人物。
```

```text
$golden-aether-cinema 一只停在古铜天文仪上的白色猫头鹰，竖版构图。
```

上传自己的照片后，也可以说：

```text
使用 $golden-aether-cinema 重绘这张照片，保留人物身份与原构图。
```

想控制画面，只需在同一句话中补充“近景”“全身”“竖版”“夜景”“没有人物”等要求。

## 工作方式

Skill 读取两张随包参考图，提取用户描述中的主体、动作、环境与约束，将其与固定风格规则组合，再交给宿主图像工具。参考图用于光色与材质指导，不用于默认复制原人物身份或构图。

默认使用宿主提供的内置图像生成工具，不包含独立图像模型、API 服务或 API 密钥。宿主不具备生图能力时，会说明限制并输出可用提示词。结果会受宿主模型、参考图支持情况和生成随机性影响，不能保证逐像素复刻。
